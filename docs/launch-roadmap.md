# Launch Roadmap

## Milestone 0. Baseline

Фокус:

- документация
- env policy
- health-checks
- migration-first backend

Выход:

- репозиторий описывает реальный продукт
- запуск и деплой можно автоматизировать

## Milestone 1. Real Data

Фокус:

- dashboard
- weather by field coordinates
- marketplace listing enrichment
- services без placeholder-поведения

Выход:

- пользователь видит реальные данные вместо демонстрационных эвристик там, где это критично для доверия

## Milestone 2. Core Expansion

Фокус:

- crop details module
- provider profiles
- reviews / trust
- regional chat channels

Выход:

- v1 покрывает рабочий цикл фермера: планировать, выращивать, продавать, искать услуги, общаться

## Milestone 3. Release Hardening

Фокус:

- roles & permissions
- logging & monitoring
- API error handling
- regression matrix for web + Capacitor

Выход:

- controlled launch candidate

## Milestone 4. Post-Launch

Фокус:

- Android shell
- subscriptions monetization
- advanced analytics
- market signals

Выход:

- рост поверх стабильного v1, а не вместо него
