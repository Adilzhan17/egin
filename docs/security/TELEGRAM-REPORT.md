EGIN Security Report

1) Что нашли
Пробелы в отзыве доступа, MFA, сессиях, проверке файлов и правах БД; уязвимые зависимости и компоненты Docker-образов.

2) Что исправили
Добавлены Argon2id, MFA для чувствительных ролей, ограничения входа, отзыв/ротация сессий, проверка файлов и прав, security headers. API получает ограниченную роль PostgreSQL. Включены проверки секретов и CVE в CI. Образы API/web проходят High/Critical scan.

3) Что осталось
Системные CVE в PostgreSQL/inference без готовых обновлений для используемых Debian-веток. Проверку HTTPS, firewall, секретов и фактических настроек production выполняет контрибьютор с доступом к серверу. Security gate пока красный.

4) Критические рекомендации
Не обходить проверки и не выкатывать до закрытия ревью. Проверить backup/restore, passkeys сотрудников и совместимый rollback. После обновления остановить старые API с bootstrap-доступом к БД.
