# Проверка мобильного интерфейса

Дата: 24 сентября 2026.

## Результаты

- `cd frontend && npm run build` — успешно; TypeScript и статический экспорт проходят.
- ESLint — без ошибок и предупреждений в новых компонентах навигации, главной, чата, справки, мобильных инструментов, а также в изменённых page, layout, sidebar, map-overlay, button и EginToolbar. Это выборочная проверка, не утверждение о всём репозитории.
- `git diff --check` — успешно.
- Chromium / Playwright: ширины 320, 390, 768 и 1440 px. Проверены главная, меню, список чатов, переписка, открытие инструментов карты и сохранение языка после перезагрузки.
- axe-core: на главной и в диалоге чата нет выявленных нарушений WCAG 2 A/AA и 2.1 AA на всех четырёх ширинах.
- Проверены отправка и повтор после ошибки; отдельные черновики для бесед; выбор готового вопроса без отправки; ограничения 500 символов для группы и 1000 для личных сообщений.
- Дополнительно проверены ошибка и повтор загрузки главной и списка чатов; пустой список и поиск без результата; кнопка «Назад» браузера; отмена устаревшего ответа при быстром переключении бесед; сохранение нового черновика во время отправки; единственный POST на нажатие; удержание фокуса внутри диалога.
- Поле ввода и отправка доступны при окне 390×420 и в горизонтальной ориентации 844×390.

## Границы проверки

Проверки выполнены на производственной сборке с тестовыми ответами API. Сообщения реальным пользователям не отправлялись. Работа с настоящим сервером, внешними картографическими сервисами и сохранение геометрии в этих проверках не подтверждались.

Эмуляция Chromium проверяет раскладку и взаимодействия, но не заменяет физические iPhone/Android, реальную экранную клавиатуру, Safari, полевые условия и проверку с фермерами целевой возрастной группы. Автоматический аудит доступности не является полной ручной проверкой WCAG.
