# Учебный стенд обмена с 1С

Это отдельный локальный OData-симулятор, **не 1С и не реальная база**. Его записи и учётные данные синтетические, а профиль и данные стенда хранятся отдельно от обычного EGIN в системном временном каталоге `egin-one-c-demo`. Сервер слушает только localhost. Никакие внешние адреса через учебный адаптер не вызываются; основной API и его проверка HTTPS/DNS не меняются.

После установки зависимостей и `pnpm build` из корня репозитория:

```sh
cd apps/api
node scripts/one-c-demo.mjs
```

Откройте `http://localhost:4955`, зарегистрируйте отдельный учебный профиль, затем перейдите в «Настройки → Подключённые сервисы → 1С:ERP АПК». Параметры **только для учебного стенда**:

- Адрес: `https://demo-1c.example.com/odata/standard.odata/`
- Пользователь: `demo`
- Пароль: `egin-demo-only`
- Каталог: `Catalog_Fields`; идентификатор: `Ref_Key`; название: `Description`; площадь: `Area`; широта: `Lat`; долгота: `Lon`; единица площади: гектары.

Проверьте подключение, настройте соответствия полей и выберите культуру по умолчанию (например, пшеницу), затем посмотрите предварительные записи и импортируйте их. Повторный импорт не должен создавать дубликаты. Автоматические проверки: `node --test tests/one-c-demo.test.mjs tests/one-c-flow.test.mjs` из `apps/api`. Настоящая совместимость с 1С требует отдельной проверки на разрешённой публикации клиента.
