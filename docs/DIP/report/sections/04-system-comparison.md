# 4. Existing System Comparison

The source review compares **EGIN v0.3** [18] with **Cropwise Operations** [14], **EOSDA Crop Monitoring** [15], **AGRIVI** [16] and **AgroSignal.Expert** [17]. The compact matrix retains four common criteria from the detailed comparison. Competitor entries summarise the reviewed product documentation, not hands-on comparative testing.

| Criterion | EGIN | Cropwise | EOSDA | AGRIVI | AgroSignal |
|---|---|---|---|---|---|
| Offline support | Saved local data | Mobile scouting | Mobile scouting | Mobile records | Mobile scouting |
| Plot weather | Coordinate forecast | Field forecast | Field forecast | Field forecast | Weather module |
| Satellite indices | Outside scope | Available | Available | Available | Available |
| Built-in KZ EGKN lookup | Implemented | Not documented | Not documented | Not documented | Not documented |

EGIN’s proposed niche is convenient access to Kazakhstan’s cadastral boundaries alongside local storage, forecasts and integration with existing accounting data. Competitor boundary workflows described in the source comparison use drawing or imported geographic files. “Not documented” is a limit of the reviewed evidence, not proof that a capability could never exist.

Established products offer broader satellite monitoring and commercial integrations. EGIN currently provides a sensor registry rather than live telemetry, and its illustrative 3D scene does not replace those capabilities.

EGIN’s browser entry lowers the installation barrier. Capacitor mobile delivery remains a release-stage objective. Offline, security and integration mechanisms exist in the source, but comparative speed, usability, agricultural benefit and complete end-to-end acceptance have not yet been measured.
