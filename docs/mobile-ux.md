# Мобильный интерфейс Egin-KZ

Основная аудитория по заданию владельца: фермеры 50+, которые открывают платформу в браузере телефона и могут редко пользоваться цифровыми сервисами. Главный критерий — понятность действия, а не декоративность.

## Принятые правила

- Пять постоянных разделов: Главная, Поля, Рынок, Чат, Меню. Услуги, новости, профиль, язык и помощь доступны из меню. На компьютере — подписанная боковая навигация.
- Первый экран отвечает на вопрос «Что хотите сделать?». Подробные прогнозы раскрываются отдельно. Нет вымышленных культур, доходов и региона для заполнения пустого экрана.
- Основной текст — 16 px, кнопки действий — от 48 px, названия действий — простыми словами. Для времени и вспомогательных подписей допустим меньший размер. Фокус клавиатуры должен быть видимым.
- Используем существующий зелёный цвет, светлые поверхности, одну гарнитуру и спокойные состояния. Поддерживаем уменьшение анимации.
- На телефоне список чатов и переписка — отдельные экраны. Текст сохраняется при ошибке и при переключении бесед в пределах открытого приложения. Автоматической повторной отправки нет. Быстрый вопрос заполняет черновик, отправку подтверждают кнопкой.
- Чат учитывает visualViewport и безопасные области экрана; список сообщений прокручивается отдельно от ввода. Обновление с сервера — каждые 12 секунд, без сброса чтения старых сообщений.
- Русский и казахский доступны в меню; выбор сохраняется. Разделы отражаются в URL, чтобы работали перезагрузка и история браузера.
- Обе реализации карты используют одну мобильную панель: добавление поля и подписанный список инструментов.

## Источники по заданию владельца

- [Impeccable](https://github.com/pbakaus/impeccable): адаптация интерфейса под мобильный контекст, режим Operate, доступность и проверка готового результата.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): доступность, сенсорные цели, навигация и состояния интерфейса.
- [Taste Skill](https://github.com/leonxlnx/taste-skill): соответствие аудитории и сохранение рабочего стека при улучшении существующего интерфейса. Декоративные приёмы для лендингов не применяем к рабочим экранам фермеров.

При конфликте эстетических рекомендаций приоритет имеют понятность, читаемость и реальные задачи пользователя.
