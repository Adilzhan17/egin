# Demo marketplace photographs

These photographs illustrate the explicitly labelled EGIN demo catalog. They do not depict a real seller's stock or substantiate the demo listing's location, price, brand, specifications, ownership, or availability.

`../demo-catalog.json` records each photograph's original Commons page, author, license, license URL, and original file URL. The importer includes attribution in the listing description. Photos retain their original composition and have only been resized to at most 1000 × 1000 pixels and converted to WebP.

Each image remains subject to its recorded license; CC BY-SA images retain that license. Public-domain and CC0 images are identified individually. The metadata and credits must accompany any redistribution.
